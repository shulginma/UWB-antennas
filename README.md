# Использование UWB-антенн для задач точного позиционирования трамвайных вагонов

Как использовать UWB для определения положения трамвая и где разместить антенны, чтобы они работали рядом с металлическим кузовом? Этот репозиторий содержит статью, в которой мы разбираем задачу и начинаем с практической проверки двух плат Qorvo DW3000.

UWB рассматривается как дополнительный источник информации на участках, где спутниковая навигация работает нестабильно. Идея — установить опорные узлы вдоль пути, измерять расстояния до бортового узла и учитывать известную геометрию рельсового маршрута.

## Что уже сделано

Проведён опыт с двумя платами DW3000. Одну закрепили неподвижно, другую перемещали по прямой с остановками на эталонных отметках. Измерения выполнялись при удалении от опорной платы и на обратном проходе. В ходе опыта также проверяли получение показаний при препятствиях.

Показания плат снимали на видео, затем извлекали численные значения в общую таблицу. Расстояния до контрольных отметок приняты эталонными, настройки плат записаны отдельно.

Для анализа ошибок использованы **925 ненулевых показаний на 13 эталонных расстояниях от 20 до 300 м**. Пустые и нулевые значения исключены, повторные замеры на одной отметке объединены. Реальные скачки показаний сохранены — именно они важны для оценки будущей системы.

Текущий этап даёт исходную характеристику дальномерного канала. Сравнение мест установки антенн на кузове и проверка координат реального вагона ещё впереди.

## О чём статья

- Зачем трамваю локальная UWB-система и как она может дополнять спутниковую навигацию.
- Как измерение времени распространения сигнала связано с расстоянием и зачем нужна калибровка.
- Почему ошибка дальности не равна ошибке координаты вагона.
- Как ориентация антенны, металлический кузов и геометрия опорных узлов влияют на постановку задачи.
- Что показал опыт с двумя платами: смещения, разброс и крупные скачки.
- Какие испытания нужны для перехода от свободно установленных плат к бортовому узлу.

Полный текст и список источников находятся в [article.tex](article.tex).

Близкие к эталону показания получались и на большой дальности. При этом на части отметок наблюдались значительные скачки. Например, на 180 м медиана составила 180,98 м, но отдельные показания доходили до 395,89 м. Поэтому одной медианы недостаточно для оценки качества.

При чтении результатов стоит учитывать:

- Таблица объединяет повторные замеры, полученные в разное время и при разных обстоятельствах. Она описывает опыт в целом.
- На 300 м менялись несколько настроек одновременно: Channel, Gain и Preamble. Эти данные не дают отдельного сравнения каналов 5 и 9.
- Получение показаний на 300 м не означает гарантированную рабочую дальность.
- Извлечённые из видео значения могут повторять один результат на дисплее. Их количество не равно числу независимых радиообменов.
- Доля успешных обменов и точность координат трамвая в этом опыте не определялись.

Полная таблица со смещением, стандартным отклонением и 95-м процентилем абсолютной ошибки приведена в статье.

## Что дальше

1. **Калибровка.** Подобрать общую поправку пары на отдельной дистанции и проверить другие расстояния без подстройки.
2. **Ориентация.** Сравнить показания при повороте и наклоне одной платы, сохранив остальные условия.
3. **Металлическое основание.** Проверить влияние листа металла и зазора между ним и антенной.
4. **Препятствия.** Отдельно исследовать металл за антенной и перекрытие прямого пути между узлами.
5. **Настройки.** Сравнить конфигурации на одинаковых расстояниях при неизменном креплении.
6. **Установка на вагоне.** Сопоставить доступные места монтажа, затем проверить выбранную систему с независимым эталоном положения.

Для новых испытаний планируется прямая запись измерений по UART или USB: время, номер попытки, расстояние, результат обмена и действующие настройки. Это позволит оценивать не только ошибку, но и доступность измерений и длительность провалов.

## Сборка PDF

### GitHub Actions

Workflow [Build PDF](https://github.com/MICRONAME/UWB_antennas/actions/workflows/build.yml) запускается при отправке изменений в ветку `main`, при создании или обновлении pull request в `main`, а также вручную через **Run workflow**.

Сборка использует Tectonic на Windows, где доступен шрифт Times New Roman. После успешного запуска:

1. Откройте [Actions](https://github.com/MICRONAME/UWB_antennas/actions).
2. Выберите успешный запуск **Build PDF**.
3. В разделе **Artifacts** скачайте `UWB-antennas-article-pdf`.

Артефакт содержит `article.pdf` и хранится 30 дней. Обновление PDF, отдельно добавленного в корень репозитория, этим workflow не выполняется.

### Локально через Tectonic

Потребуются [Tectonic](https://tectonic-typesetting.github.io/) и шрифт **Times New Roman**, который явно указан в текущем исходнике статьи.

В Bash-совместимой оболочке из корня репозитория выполните:

```bash
mkdir -p build
tectonic -o build article.tex
```

В PowerShell:

```powershell
New-Item -ItemType Directory -Force -Path build | Out-Null
tectonic -o build article.tex
```

Результат появится в `build/article.pdf`.

При установленном GNU Make и доступных Unix-командах, например в подходящем окружении Git Bash или WSL, можно использовать:

```bash
make article
```

На Linux для текущего исходника также потребуется Times New Roman; наличие одного Tectonic не заменяет установку шрифта.

### Локально через XeLaTeX

При установленном TeX-дистрибутиве с XeLaTeX, необходимыми пакетами и Times New Roman выполните:

```bash
xelatex article.tex
xelatex article.tex
```

Повторный проход нужен для обновления ссылок и нумерации. В этом случае файл `article.pdf` появится в корне репозитория.
